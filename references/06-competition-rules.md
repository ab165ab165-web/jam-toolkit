# 06 · 比赛规则（赛道 / 材料 / 评分 / API 要求）

> 来源：官方 **2026 Unity 中国开发挑战赛 赛制细则** `https://unity.cn/ucdc2026/rules`（实读于 2026-10-16）。
> ⚠️ 上海站「24h Vibe Coding 创作挑战」若有**单独补充规则**，以现场/主办方为准。

## 1. 通用技术要求

- **必须基于「团结引擎」完成核心开发**；须契合对应赛道的形态、平台与技术规范。
- **平台兼容**：支持小游戏、手游、PC 端游等全品类，作品需具备**完整的可运行体验**。
- **必须留存完整、真实的项目开发记录。**
  > **无合规开发记录、未按要求使用指定工具的作品，一律判定为无效参赛作品。**
- **内容合规与完整性**：内容须符合法律法规 / 网络内容传播规范；**不接受仅提交文字方案、概念设定、半成品资源或无可运行体验的项目**。

## 2. 赛道特别要求

| 赛道 | 要求 | 看重 |
|---|---|---|
| **Codely+ 赛道** | 核心代码 / 关键玩法逻辑 / 重要系统模块 **必须有 Codely 的实质性参与生成或辅助开发**；需积极使用 Codely | 与 Codely 的**深度共创** |
| **AI+ 赛道** | 在开发 / 美术 / 音频 / 剧情 / 关卡等核心环节**使用 AI 工具辅助创作**（工具不限；「**任意** AI 工具」的表述出自**评分 §5.2**，非赛道特别要求） | 创作者**原生开发能力**（我主导，AI 加速） |

## 3. 作品原创与版权

- 核心创意、游戏设计、核心代码**须原创**；已有作品参赛需在赛期有明显迭代 / AI 集成。
- **允许使用开源资源**或已获合法授权的素材，**必须在提交文档中明确标注来源及使用范围**。
- 全程无版权纠纷、无权属争议；不得侵权 / 盗用 / 抄袭 / 搬运 / 篡改。

## 4. 提交材料（百度网盘，提取码 `UCDC`，有效期 ≥1 年）

1. **可执行文件 / 安装包**（能正常运行）。
2. **演示视频 3–5 分钟**：实机画面 + 核心玩法；封面 16:9 (jpg/png)；**须含 AI 辅助开发过程录屏**（**Codely+ 赛道需 Codely 辅助开发录屏**）。
3. **作品说明文档 PDF**：项目简介 + **AI 工具说明**（列出 AI 工具名称、应用环节、AI 生成内容 vs 最终效果对比）；**Codely+ 赛道需提供 Token 用量截图**。
4. **AI 工具使用日志**。
5. **项目工程截图 / 核心代码片段**：用于**验证团结引擎使用情况**（**必交**）。
6. **（可选）商业化计划书**：面向孵化基地的团队可补充提供。
- 征集期可多次覆盖提交；**截止 2026-10-31 23:59**，之后无效。

## 5. 评分

- 通用核心维度 **50%**；AI 应用维度 **40%**；平台差异化权重 **10%**（小游戏=包体/即点即玩；移动端=操作适配/机型兼容；PC=画质上限/系统复杂度/沉浸感）。

## 6. ⚠️「必须用官方 API 吗？」

**不是「必须只用官方 API」**，但**取决于赛道**：

- **Codely+ 赛道** → **是的，官方 Codely（Token）必须实质使用**：核心模块要有 Codely 实质参与，且要交 **Token 用量截图 + Codely 录屏**——否则判无效 / 重扣分。⚠️ 规则**并未**提及第三方模型、也未对其禁止或排序（「只能当辅助」属推断，非规则原文）；第三方工具的使用应与所报赛道要求一致，并**如实登记**在「AI 工具说明」里。
- **AI+ 赛道** → **不必须官方 API**：规则明确「使用**任意** AI 工具辅助」。仍需登记 AI 工具使用。
- **无论哪条** → 团结引擎是强制；素材要合规并标注来源；开发记录 / AI 工具日志要留全。

> **一句话**：官方 API = 官方 **Codely Token**。走 Codely+，它**必须真用**；走 AI+，它可选。**先确认报了哪个赛道**，规则据此分叉。
