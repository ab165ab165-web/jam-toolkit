# 15 · 美术制作管线（多方位概念图 → 拆件 → Blender → 绑骨）

> 老板定的流程：**玩法先好玩 → 同场景多方位 AI 效果图 → 标出需单独建模的东西 → Blender 调整 → 绑骨完成。**
> 前提铁律：**没确认玩法好玩，不动美术**（对应 24h 赛的「前 6h 灰盒」）。

## 五步

| 步 | 做什么 | 用什么 |
|---|---|---|
| 0 | **玩法先好玩**（灰盒跑通闭环） | 几何体 + 2D movers（asset-pack/scripts） |
| 1 | **同一场景多方位 AI 效果图**（正面/侧面/背面/俯视…） | TJGenerators `generate_image`（`generate_image` 可带 `aspect_ratio`/尺寸）或外部生图 |
| 2 | **拆件清单**：标出场景里**需要单独建模**的物件 | 出「refs / resolved / missing」表（呼应「先把一个单位的全部部位找齐再开工」） |
| 3 | **建模** | TJGenerators `generate_3d_model` 出模型 → **Blender 调整**（修形/比例/UV） |
| 4 | **绑骨 + 动画 → 完成** | TJGenerators `generate_rigged_model` / `generate_animated_character` / HunyuanMotion |

## ⚠️ 2D vs 3D 分岔

| 若走 **2D 固定构图**（当前方向） | 若走 **3D** |
|---|---|
| 第 1 步「多方位」只为**理解空间**；实际只需**同机位正视图**（正常态/异常态两版） | 第 1 步**必须多方位**（当建模参照） |
| **跳过 Blender / 绑骨**；需要动作用 **2D 序列帧**（`generate_sprite_sequence` / 4×4 精灵表） | 全流程照上：建模 → Blender 轻调 → **绑骨** |
| 美术＝手绘/淡彩静帧（同机位只换笔触） | 美术＝3D 模型 + 骨骼动画 |

> 24h 现实：Blender **只做「够用即止」**，优先 TJGenerators 一键出；精雕留赛外。

## 我们现状对照

- ⚠️ **缺**：**同场景「多方位」图**（若走 3D 才需要）；**拆件清单模板**（第 2 步）。
