## Why generate instead of download?

For a 24h jam we need 3 distinct shoot sounds that **won't fail a license
audit**. Common CC0 sources I tried:

| Source | URL | Issue |
| --- | --- | --- |
| Kenney Impact Sounds | https://kenney.nl/assets/impact-sounds | No laser/shoot category — all impact hits |
| Kenney Digital Audio | https://kenney.nl/assets/digital-audio | UI sounds, not shoot |
| Kenney Sci-Fi Sounds | https://kenney.nl/assets/sci-fi-sounds | Has lasers but download requires itch.io bundle or donation prompt — not safe for prep pack |
| OpenGameArt "laser" search | https://opengameart.org | Top results are CC-BY (require attribution) or CC-BY-SA (viral); CC0 laser packs rare |
| Freesound | https://freesound.org | Requires API key + per-file attribution; many are CC-BY-NC (prohibits commercial) |

So: generate with ffmpeg's built-in oscillators + filters, release as CC0.
The resulting `.ogg` files are yours to do whatever with — no source code
license applies to the WAV waveform.

## How they were made (exact commands)

```bash
# shoot_001 — laser zap (mid pitch)
ffmpeg -f lavfi -i "anoisesrc=color=pink:duration=0.20:amplitude=0.6" \
       -af "highpass=f=200, lowpass=f=3000, volume=0.5,
            tremolo=f=60:d=0.9, aecho=0.8:0.8:60:0.4,
            afade=t=in:st=0:d=0.005, afade=t=out:st=0.12:d=0.08,
            aformat=channel_layouts=stereo" \
       -ar 44100 -ac 2 -c:a libvorbis -q:a 5 shoot_001.ogg

# shoot_002 — high-pitched laser zap
ffmpeg -f lavfi -i "sine=frequency=2200:duration=0.08" \
       -af "volume=0.5, tremolo=f=200:d=0.95, aecho=0.8:0.8:80:0.5,
            afade=t=out:st=0.05:d=0.03, aformat=channel_layouts=stereo" \
       -ar 44100 -ac 2 -c:a libvorbis -q:a 5 shoot_002.ogg

# shoot_003 — low cannon / gun
ffmpeg -f lavfi -i "anoisesrc=color=brown:duration=0.40:amplitude=0.7" \
       -af "highpass=f=50, lowpass=f=400, volume=0.7, aecho=0.9:0.9:120:0.5,
            afade=t=out:st=0.2:d=0.2, aformat=channel_layouts=stereo" \
       -ar 44100 -ac 2 -c:a libvorbis -q:a 5 shoot_003.ogg
```

Re-run any of these from a Linux/macOS shell to regenerate. ffmpeg ≥4.4
required (`lavfi` `anoisesrc` filter).

## When the synthesized sounds aren't enough

If you want richer / more musical laser / shoot sounds, use the procedural
SFX generators in `open-assets/sfx-generators/README.md`:

- **jfxr** (https://jfxr.frozenfractal.com) — best for retro pew-pew, "laser"
  preset, mutate a few times
- **Bfxr2** (https://www.bfxr.net) — same engine as jfxr, "Laser" preset
- **ChipTone** (https://sfbgames.itch.io/chiptone) — chiptune laser variants
- **jsfxr** (https://sfxr.me) — same algorithm as sfxr/jfxr, in JS / browser

Output of all 4 tools is yours (per the tool licenses); regenerate 1 s01.wav
to disk and replace these .ogg files.
