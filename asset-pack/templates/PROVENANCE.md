```

```

类型枚举：
- `idea` — 灵感 / 设计决定
- `prompt` — 我对工具说的话（完整 prompt 摘要）
- `tool` — 工具调用结果摘要
- `diff` — 代码/资源改动（关键 diff 摘要）
- `asset` — 拉取的素材（含来源 URL + license）
- `screenshot` — 截图说明（路径 + 内容描述）
- `build` — 构建结果（target, OK/fail, log path）
- `test` — 自检 / Play Mode 测试结果
- `bug` — Bug 记录 + 修复方案
- `decision` — 关键取舍与理由
- `submit` — 提交相关步骤
