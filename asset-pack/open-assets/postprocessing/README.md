Total: 3 effects. Designed to be cheap on Built-in RP at 60 fps on integrated graphics.

## How to set it up in Unity (Built-in Render Pipeline)

1. **Install Post-Processing Stack v2** (Unity Package Manager → search "Post Processing" → install 3.4.x — the **last version that supports Built-in**; v3+ is HDRP/URP only).
2. **Copy** `JamKit_BuiltIn_PostProcessing_Profile.asset` + `.meta` into your project's `<unity-project>/Assets/Settings/`.
3. **Add** a `PostProcessVolume` component to your Main Camera GameObject:
   - Check `Is Global`
   - Drag `JamKit_BuiltIn_PostProcessing_Profile` into the `Profile` field
4. **Add** a `PostProcessLayer` component to the same Main Camera:
   - Layer: choose a layer (e.g. `PostProcessing`) and set your Main Camera's culling mask to include that layer
   - Trigger texture filtering mode: **Bilinear**

Done — you should see Bloom + Vignette + Color Grading kick in.

## URP users: you don't need this

The 2 URP-compatible `.asset` files in `../cinemachine-urp/VolumeProfiles/` are
still your go-to. We **kept both** — Built-in RP version is *additive*, not a
replacement:

| Pipeline | Profile(s) to use |
| --- | --- |
| **Built-in RP** | `postprocessing/JamKit_BuiltIn_PostProcessing_Profile.asset` (this folder) |
| **URP** | `cinemachine-urp/VolumeProfiles/JamKit_URP_PostProcessing_Profile.asset` *or* `CinemachineSampleSceneProfile_URP.asset` |
| **HDRP** | HDRP has its own Volume Profiles built-in (different format); use the HDRP package's samples |

The 3 profiles share parameter names where possible (Bloom intensity,
Vignette intensity) so a designer can swap between them with similar results.

`m_OverrideState: 1` means the value below it overrides the global default;
`0` means "fall back to a higher-priority Volume". Set overrides only for the
parameters you actually want to enforce; otherwise let the stack fall back.
